# Components

The pilot did not add a component library. It uses the existing `button.btn`, `input`, and a small menu:

- Chat title button: `.dc-chat-title`, `aria-current` when selected.
- Actions button: `aria-haspopup="menu"`, label `Actions for <title>`.
- Menu items: Rename, Archive.
- Rename form: text field, Save title, Cancel.

Buttons, dialogs, and the composer stay on their current implementations.
