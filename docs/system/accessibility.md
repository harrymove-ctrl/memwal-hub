# Accessibility

The new menu is a button plus `role="menu"` items. It is reachable by keyboard as buttons. Focus return is the existing dialog behavior, not a new trap.

Not measured on a rendered page in this pass: contrast ratios, 200% zoom, and target sizes in pixels. Do not treat this file as a WCAG audit.

Reduced motion: `.dc-wave`, `.dc-caret`, and `.dc-intro` already stop animating under `prefers-reduced-motion: reduce`.
