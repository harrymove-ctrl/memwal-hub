# PRD: Example preview

Preview example is optional and local.

- The user starts it with Preview example. It is not the default run.
- The panel says "Example — no model calls or remote writes" for the whole preview.
- Files and findings are the fixed sample list. They are labeled example, not uploaded records.
- Progress between file, review, and save is a timer in the browser. It is not a tool call.
- Preview save says it was not sent. It does not call `/memory/remember` or `/discovery/memories`.
- Console upload is unavailable. The control is disabled. There is no Retry upload and no Failed status.
- Download report writes a text file in the browser and says it was not uploaded.
- The composer says Enter does not send a live message. Enter does not call the model.
- Exit example and Open chat stay available through file, reading, analyzing, review, and save stages. Exit returns to the idle panel. Open chat uses the same dirty-revision path as the idle control.
- Reduced motion: the jump-to-latest scroll uses `auto` when the user prefers reduced motion. The example steps are short timers, not a looping animation.
