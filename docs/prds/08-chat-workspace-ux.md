# PRD: Chat workspace

The conversation list is navigation, not a set of equal actions.

- One project select sits above the list.
- Each chat is one truncated title. The full title is on the control's title attribute and in Rename.
- Rename and Archive are inside Actions for that title. Archive does not delete Walrus facts.
- Hide chats removes the list. Show chats brings it back.
- The thread stays the primary column, at most 760px wide.
- Suggested facts wrap. Saving them is still an explicit project-Memory write.
- This pass does not add a new font, color, or component library.
